# Hotel Customer Segment Analysis

## Project Overview

This project analyzes hotel booking trends, cancellation history, and seasonal pricing to identify which customer segments contribute the most to occupancy volatility. The insights will help the hotel make better pricing and occupancy planning decisions.

## Stakeholder

The primary stakeholder is the **Revenue Management Team**. They will use the dashboard to understand customer behavior, reduce occupancy fluctuations, and improve revenue through better forecasting and pricing strategies.

## Business Objective

Identify the customer segments that have the greatest impact on hotel occupancy volatility.

## Available Data

The dataset includes:

* Booking trends
* Cancellation history
* Seasonal pricing records

The dataset does not clearly specify customer segment labels, occupancy metrics, revenue details, or external factors such as holidays and events.

## Project Deliverable 

A dashboard that:

* Visualizes booking and cancellation trends
* Compares customer segments
* Highlights occupancy volatility
* Provides actionable insights for revenue planning

## Open Assumptions

Some details are not defined in the problem statement, including:

* How customer segments are categorized
* How occupancy volatility is measured
* The time period of the data
* Whether the final output should be a dashboard, report, or predictive model
